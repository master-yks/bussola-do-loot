# Protótipo experimental em Rust

Esta pasta preserva o protótipo alternativo em Rust separado da raiz do projeto para manter o repositório principal focado na edição oficial em **.NET 10** (`src/`), que é a versão testada e distribuída para Windows.

> A variante gráfica em Rust compilou com a toolchain GNU, porém encerrou durante a inicialização em testes anteriores e permanece apenas como referência de desenvolvimento, usando armazenamento separado em `%APPDATA%\ChestCounter-Rust`.
